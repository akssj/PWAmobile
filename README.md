 ## uruchomienie
  + zaisntaluj mysql 12
  + pobierz repozytorium z brancha main
  + Uruchom konsole systemową jako administrator
  + przejdź do głównego folderu aplikacji (/PWAmobile)
  + uruchom komende npm install
  + uruchom komende npm install axios
  + uruchom komende npm run dev (frontend aplikacji)
  + Uruchom nową instancje konsoli systemową jako administrator
  + przejdź do folderu /PWAmobile/src/backend
  + uruchom komende npm install
  + uruchom komende npm install bcryptjs
  + uruchom komende npm start (backend aplikacji)
  + aplikacja dostępna na http://localhost:5173/
